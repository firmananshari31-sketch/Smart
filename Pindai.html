Sebelum mulai

Siapkan hal berikut:

  • HP Android atau laptop, dengan browser Chrome.
  • Koneksi internet, karena pemeriksaan memakai AI.
  • API key Anthropic milik Bapak/Ibu sendiri. Jangan dibagikan ke orang lain.
  • Kunci jawaban atau rubrik penilaian, dan foto lembar jawaban siswa yang terang dan tidak buram.

Baca panduan ini sampai selesai sebelum mulai.

Langkah cepat
  1. Buka menu Atur (menu ke-9). Isi API key, lalu isi KKM.
  2. Buka menu Nilai (menu ke-1). Pilih kelas, rombel, mapel, bab, dan materi. Isi Tujuan Pembelajaran (TP).
  3. Buka menu Rubrik (menu ke-2). Tulis kunci jawaban, atau buat draf kunci dari foto soal. Pilih kebijakan penilaian.
  4. Kembali ke menu Nilai. Isi nama siswa, lalu ambil foto lembar jawabannya dengan kamera belakang, atau pilih foto dari galeri. Tekan Tambah siswa ini ke antrean.
  5. Tunggu sampai proses selesai, lalu buka menu Hasil (menu ke-3) untuk melihat nilai dan alasannya.
  6. Periksa nilai yang ditandai ragu. Perbaiki bila perlu.
  7. Buka menu Rekap (menu ke-4) untuk mengunduh Excel atau PDF.

Setelah lancar, ulangi langkah 4 sampai 6 untuk siswa berikutnya.

Panduan per menu

Menu ada di bar paling bawah layar. Tiga menu tampil per halaman, dan titik kecil di atas bar menunjukkan halaman yang sedang dibuka. Geser bar ke kiri atau kanan untuk pindah halaman. Angka kecil di pojok tiap tombol adalah nomor menu.

Halaman 1

  • 1. Nilai: memilih kelas, rombel, mapel, bab, materi, dan TP, serta memasukkan lembar jawaban siswa. Pilihan ini ikut berpindah ke menu lain.
  • 2. Rubrik: menulis atau membuat kunci jawaban, memilih rubrik, dan memilih kebijakan penilaian. Kebijakan bisa diunggah dari file docx, xlsx, pdf, atau txt.
  • 3. Hasil: daftar nilai dan alasan tiap siswa. Bisa disaring menurut kelas, mapel, dan materi. Nilai yang ragu ditandai di sini.

Halaman 2

  • 4. Rekap: rekap nilai per kelas dan per materi, dengan pilihan jenis. Bisa diunduh ke Excel (.xlsx) atau PDF.
  • 5. Analisis: ringkasan nilai dan grafik per kelas, mapel, dan materi. Grafik bisa digabung atau dipisah per bab, lalu diunduh ke PDF atau Word. Tombol Buat analisis AI menyusun ulasan hasil.
  • 6. Rapor: menyiapkan nilai untuk rapor siswa.

Halaman 3

  • 7. Remedial: daftar siswa yang perlu remedial.
  • 8. Soal: bank soal. Tombol Buat soal dengan AI membantu menyusun soal baru.
  • 9. Atur: API key, KKM, tampilan warna, cadangan data, gabung kelompok, dan kelola nama.
Cadangan data

Data nilai tersimpan di browser HP atau laptop ini. Karena itu, buat cadangan secara rutin, misalnya setiap selesai satu kelas.

Membuat cadangan

  1. Buka menu Atur (menu ke-9).
  2. Tekan Simpan cadangan (.json). File akan terunduh.
  3. Simpan file itu di tempat yang aman, misalnya Google Drive atau folder penyimpanan.

Memulihkan cadangan

  1. Buka menu Atur.
  2. Tekan Pulihkan dari cadangan, lalu pilih file cadangan.

Pindah ke HP lain

  1. Buat cadangan di HP lama.
  2. Pindahkan file cadangan ke HP baru, misalnya lewat WhatsApp ke nomor sendiri atau Google Drive.
  3. Di HP baru, buka aplikasi, lalu pulihkan dari cadangan.

Pada sebagian HP, tombol kirim langsung ke aplikasi lain tidak selalu berhasil untuk file. Jika itu terjadi, simpan file dahulu, lalu kirim secara manual.

Pemakaian dan biaya API

Apa itu token? Token adalah potongan teks yang dibaca AI. Token bukan huruf dan bukan satu kata utuh. Kata pendek seperti "dan" biasanya satu token, sedangkan kata panjang bisa terbagi menjadi dua sampai tiga token. Kira-kira, satu token setara dengan tiga sampai empat huruf.

Lembar jawaban berupa foto memakai banyak token masuk, karena gambarnya ikut dibaca AI. Jawaban tertulis yang dibuat AI dihitung sebagai token keluar.

Harga sudah terisi otomatis di menu Atur, dalam USD per 1 juta token. Ubah hanya kalau harga di halaman harga Anthropic berubah. Tombol Kembalikan harga standar mengembalikan angka bawaan.

Mengunggah pemakaian dari Console

  1. Buka console.anthropic.com, lalu cari halaman penggunaan (usage). Nama menunya bisa sedikit berbeda.
  2. Pilih rentang tanggal, lalu unduh file CSV-nya.
  3. Buka menu Atur, lalu tekan Unggah CSV pemakaian dan pilih file tadi.

Mengunggah ulang file yang lebih baru aman. Baris yang tanggal dan modelnya sama akan diganti, bukan dijumlahkan dua kali.

Mengecek sisa saldo

  1. Buka halaman billing di Console dan lihat saldo yang tersisa.
  2. Di menu Atur, isi jumlah saldo dan pilih tanggalnya, lalu tekan Simpan saldo.

Aplikasi lalu menghitung perkiraan sisa saldo dari pemakaian sejak tanggal itu. Angkanya perkiraan, jadi tetap cocokkan dengan halaman billing.

Membaca ringkasan. Tabel pemakaian bulan ini tampil di menu Atur dan di bagian atas tab Hasil. Di sana terlihat token masuk, token keluar, dan perkiraan biaya per model.

Catatan: tanggal di CSV memakai UTC, jadi pemakaian dekat tengah malam WITA bisa masuk ke hari atau bulan yang berbeda.

Pertanyaan yang sering muncul

Nilai tidak muncul atau proses gagal. Periksa API key di menu Atur, lalu periksa koneksi internet. Jika masih gagal, periksa kuota akun Anthropic.

Hasil teks kunci terpotong. Pisahkan kunci menjadi beberapa bagian yang lebih pendek. Aplikasi juga memberi pesan jika teks terlalu panjang.

Nama siswa atau nama materi salah tulis. Buka menu Atur, lalu pilih Kelola nama. Perubahan otomatis mengikuti menu lain.

Foto lembar jawaban kurang jelas. Foto ulang dengan cahaya yang cukup dan kertas lurus. Nilai yang ragu tetap ditandai agar Bapak/Ibu dapat memeriksanya.

Ingin mengganti tampilan warna. Buka menu Atur, lalu pilih Tampilan.

Data hilang setelah ganti HP. Pulihkan dari file cadangan. Karena itu, biasakan membuat cadangan secara rutin.

Tombol menu tidak terlihat. Pastikan layar tidak tertutup browser. Geser bar menu ke kiri atau kanan untuk menemukan menu yang dicari.
